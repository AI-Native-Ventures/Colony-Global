# Colony Global

Colony is a desktop app for small business owners to work with an AI team. Scout, the Chief of Staff, brings work into topic conversations and asks for a person's decision before anything public, financial or consequential happens. The employees are ants.

This repository is the **public rebuild**. It reuses the Colony 2.0 engine and is replacing its old desktop interface with the [approved Colony OS design](design-reference/colony-os/README.md). The new production renderer lives in `app/`; the existing `desktop/src` is retained as migration reference while the new paths are proven. The white work area, blended rose/lilac/blue sidebar, channel-like conversations, side threads and shared conversation workspace are the design contract.

The rebuild is in progress. The shipped app's email-code path calls the account relay, imports the verified identity through the native host and checks the current account on reopen. Company entry discovers real memberships, creates an owner company, saves the person's name in that company, and saves and re-reads its shared business profile. New owners then reach the power choice. Where the native flag, Colony gateway, Stripe catalog and secure policy URLs are configured, O-05 uses signed account payments and a recoverable browser checkout. Browser tests cover these paths with a controlled host/relay, while the engine CI lane tests real account, company, profile and Stripe payment handlers against disposable Postgres and Redis. The account credit wallet is not yet a company wallet; own-plan connection, Scout execution and weekly budget enforcement still need implementation. Installed-app sign-in and checkout, real email and Stripe delivery, deployment and customer use remain separate proof gates. The [production coverage ledger](docs/production-coverage.md) shows which approved screens are actually wired. The [repository design](docs/superpowers/specs/2026-10-14-colony-global-rebuild-repository-design.md) defines the product and CI boundary; the [first-run plan](docs/superpowers/plans/2026-10-14-first-run-auth.md), [company-entry gate](docs/superpowers/plans/2026-10-14-company-entry.md) and [power-and-credits gate](docs/superpowers/plans/2026-10-14-power-and-credits.md) track the current work.
